## Проверенные утверждения
- Средний размер пыли ~70 мкм, с фракцией <1–3 мкм (p.2, PE-006).
- Плотность реголита 1.3–3.1 г/см³ (p.2).
- Потенциал графитовой пластины −40…−100 В (p.3, PE-050).
- JSC-1 симулянт 125–150 мкм, контактная зарядка при −20 В (p.3, PE-051).
- Левитация возможна для частиц радиусом 0.1 мкм при угле Солнца 76.14° (p.4, PE-052).
- Инжектор: диаметр сопла 4 мкм при 8 кВ, поле 6.5×10⁹ В/м для 0.1–10 мкм (p.9, PE-056/057).
- Ускоренные частицы 400–1550 м/с для массы 9×10⁻¹⁰–1.1×10⁻⁸ г (p.10, PE-058).
- Максимальная плотность заряда 13.4 Кл/кг для радиуса ≤200 мкм (p.12, PE-059).
- Скорость частиц от удара ботинок (ходьба 1.8 м/с) ~3.6 м/с, высота ~4 м; луноход 3.56 м/с → поток до 7.12 м/с, дистанция ~31 м (p.8).
