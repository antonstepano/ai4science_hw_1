# Одноразовый запуск ДЗ 1

Выполни полностью домашнюю работу 1 «Среда и контекст» для проекта моделирования лунной пыли.

Строго следуй `AGENT.md`. В первую очередь прочитай `INDEX.md`, `STATUS.md`, `course_reference/HW1_requirements.md`.

К концу этого единственного запуска:
1. локальная библиотека проинвентаризирована и работает локальный поиск;
2. реестр литературы расширен проверенными внешними источниками;
3. есть небольшая онтология и граф понятий;
4. выполнены и задокументированы ≥6 запросов к локальному контексту;
5. собран стартовый набор ≥30 parameter evidence для будущих вычислительных моделей;
6. написан отчёт `report/HW1_environment_context.md` с приложенным содержимым `AGENT.md`;
7. обновлены `STATUS.md` и `diary.md`;
8. команда `python checks/check_hw1.py --strict` завершается кодом 0.

Внешний поиск: используй сначала кандидаты из `library/seed/sources_seed.csv`, затем расширяй через OpenAlex/Wikidata/доступный поиск. Запросы к OpenAlex формулируй по-английски. Не выдумывай метаданные и не обходи paywall.

В конце ответа кратко перечисли созданные артефакты и строку `[HW1 CHECK: PASS]` только если strict-check действительно прошёл.
