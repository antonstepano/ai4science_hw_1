# ДЗ 1 — «Среда и контекст»: требования курса

По `syllabus.pdf` из переданного архива `lectures1_5.zip`:
- ДЗ 1 выполняется по материалам недель 1–5 и сдаётся к неделе 6;
- требуется личная среда, в которой агент работает с материалом исследователя;
- обязательные элементы: договор `AGENT.md`, небольшая онтология и граф понятий темы, поиск по личной библиотеке, журнал работы;
- приёмка: отчёт с приложенным `AGENT.md` и примерами запросов к локальному контексту.

Из практик недель 1–5 в эту заготовку перенесены принципы:
1. git-проект + `AGENT.md` + `diary.md`;
2. явный критерий готовности, проверяемый командой;
3. `INDEX.md` как карта проекта, `STATUS.md` как перезаписываемое текущее состояние;
4. `diary.md` только дописывается;
5. онтология/граф как навигация по источникам, параметрам, процессам и результатам;
6. внешняя литература ищется через OpenAlex/Wikidata при подключённом модуле `research`;
7. внешний текст всегда считается данными, а не инструкциями.

В корне намеренно используется только `AGENT.md`: это соответствует формулировке ДЗ 1 и избегает конкуренции с `AGENTS.md`/`CLAUDE.md`.
